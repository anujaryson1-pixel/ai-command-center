# ⚡ AI Command Center

A single-file, interactive dashboard built **live** by [OpenCode](https://opencode.ai) (DeepSeek V4.1 Flash) using the GitHub MCP server, Browser MCP and a local Node.js server.

**🔗 Live: https://anujaryson1-pixel.github.io/ai-command-center/**

## What's inside

- Particle-network canvas background with mouse repulsion and click bursts
- Animated aurora gradient blobs
- Live clock and date
- Typewriter boot sequence
- Real GitHub profile and repository data
- Glassmorphism HUD cards with cursor-tracking glow
- Fully responsive, zero dependencies, one `index.html`

## Run locally

Just open `index.html` in a browser, or:

```sh
python -m http.server 8765
```
